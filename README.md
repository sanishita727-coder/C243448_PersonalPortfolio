# C243448_PersonalPortfolio
## How This Project Works
### 1. HTML (`index.html`) – Structure
HTML builds the content of the page. My portfolio is divided into sections:
- Navbar: links to every section
- Home (Hero): my name, title, profile photo and buttons
- About: a short introduction about me
- Skills: my programming, web and tool skills
- Education:my university, HSC and SSC details
- Projects: CropShield, LabMaster, StudyCloud, Inventory Management System
- Contact:GitHub, LinkedIn and email links
- Footer: copyright and a "Back to Home" link

### 2. CSS (`style.css`) – Design
CSS controls how the page looks:
- Dark blue theme with a light-blue accent colour
- Fixed navbar that stays at the top while scrolling
- Cards for About, Skills, Education, Projects and Contact
- Hover effects (cards lift up and borders glow)
- Alternating section backgrounds for a clean look
- Bootstrap 5 is used for the grid layout, so the site works on mobile and desktop

### 3. JavaScript (`script.js`) – Interactivity
JavaScript adds behaviour to the page:
- Smooth scrolling:clicking a navbar link scrolls smoothly to that section instead of jumping
- Automatic year:the footer year is filled in automatically, so it never goes out of date

### Technologies Used
HTML5, CSS3, JavaScript, Bootstrap 5, Git and GitHub
